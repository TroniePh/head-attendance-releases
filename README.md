Bản này bổ sung cấu hình kết nối Ronald Jack 8000T và tiến trình tải công qua LAN. Chưa kiểm thử trên thiết bị 8000T thật; cần nghiệm thu với firmware tại khách hàng.

Cập nhật bằng cách tải gói và làm theo hướng dẫn. Tạo backup trước khi cập nhật và giữ nguyên database, mật khẩu, cấu hình máy và Docker volume. Phần mềm chưa có nút tự tải/cài cập nhật. Repo chứa thông tin phát hành; mã chương trình để chạy được đóng trong các gói release.
